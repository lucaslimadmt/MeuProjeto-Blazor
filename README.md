# MeuProjeto - Blazor

Projeto desenvolvido em **C# utilizando .NET e Blazor** como parte de uma atividade acadêmica da faculdade.

A aplicação foi criada com o objetivo de praticar o desenvolvimento de aplicações web utilizando a tecnologia Blazor e os conceitos apresentados durante as aulas.

## Funcionamento

O projeto utiliza a estrutura do **Blazor** para criação de páginas e componentes web utilizando C#.

A aplicação segue a organização padrão de um projeto .NET, contendo componentes, páginas, arquivos de configuração e recursos utilizados na interface.

## Tecnologias utilizadas

- C#
- .NET
- Blazor
- HTML
- CSS

## Objetivo

O projeto tem como objetivo colocar em prática conceitos relacionados a:

- Desenvolvimento de aplicações web com Blazor;
- Criação e organização de componentes;
- Estrutura de projetos em .NET;
- Utilização de C# no desenvolvimento web;
- Criação de interfaces utilizando HTML e CSS;
- Aplicação prática dos conteúdos apresentados em aula.

## Execução

Para executar o projeto, é necessário ter o **.NET SDK** instalado.

Dentro da pasta do projeto, utilize:

```bash
dotnet restore
dotnet run
```

Após a execução, o endereço da aplicação será exibido no terminal e poderá ser acessado pelo navegador.

## Observação
